# JARVIS — Visual QA Protocol

Use this after implementation.

---

# Primary Reference

Compare the running application against:

materials/landing-page.png

---

# Objective

Determine how closely the implementation matches the intended design.

---

# Inspect

Compare:

- Overall composition
- Header
- Navigation
- Hero
- Typography
- Font sizing
- Font weight
- Spacing
- Alignment
- Widths
- Heights
- Images
- Colors
- Borders
- Radius
- Shadows
- Decorative elements
- Section transitions
- Responsive behavior

---

# Priority

Fix in this order:

1. Major layout differences
2. Incorrect proportions
3. Incorrect typography
4. Incorrect spacing
5. Incorrect imagery
6. Incorrect colors
7. Minor visual details

---

# Responsive QA

Check:

- Mobile
- Tablet
- Desktop

Look for:

- overflow
- broken grids
- text wrapping
- navigation issues
- incorrect image scaling
- spacing problems

---

# Output

Create:

.vibe/artifacts/visual-qa.md

Include:

- Visual differences
- Severity
- Root cause
- Recommended fix
- Applied fixes
- Remaining differences

Fix high-impact issues before reporting completion.
